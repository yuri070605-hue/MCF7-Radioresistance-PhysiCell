About the Project

This project was motivated by my oncology laboratory internship, where I work with breast cancer cells. I wanted to understand tumor growth and treatment response more visually before performing laboratory experiments.

Therefore, I developed a proof-of-concept computational model using PhysiCell to simulate MCF-7-like breast cancer cell growth, estrogen stimulation, radiotherapy response, oxygen distribution, and three-dimensional spheroid development.

Main aim: To visualize how estrogen, radiation dose, and the spatial tumor microenvironment may influence MCF-7-like breast cancer growth.

Methods and Main Formulas

1. Baseline cell-cycle model

The control condition used baseline MCF-7-like proliferation with no estrogen stimulation and no irradiation.

G0/G1 = 600 min
S = 960 min
G2 = 480 min
M = 120 min

Total nominal cell-cycle duration ≈ 2160 min = 36 h

2. Estrogen effect

rE2 = fE2 × rbaseline

fE2 = 1.25
E2 concentration = 1 nM
E2 starts on Day 7

Estrogen was represented as a proliferation multiplier in the current model.

3. Radiation response

SF(D) = exp(−αD − βD²)

α = 0.30 Gy⁻¹
β = 0.03 Gy⁻²

SF(2 Gy) ≈ 0.487
SF(4 Gy) ≈ 0.186

Radiation was delivered as a single 2 Gy or 4 Gy dose on Day 7.

Day 12.5 was used as the common comparison point across all six simulations.

Estrogen-only produced the highest modeled cell population. Increasing radiation dose from 2 Gy to 4 Gy produced stronger suppression of simulated growth. Surviving irradiated populations subsequently showed regrowth.

Oxygen / Hypoxia Visualization

Oxygen transport was represented using a diffusion-decay-consumption framework:

∂C/∂t = DO₂∇²C − λC − U

where C represents local oxygen concentration, DO₂ represents oxygen diffusion, λ represents decay, and U represents cellular oxygen consumption.

Each cell was colored according to its local simulated oxygen concentration.

Oxygen level Visualization color
≥35 mmHgRed
30–35 mmHgOrange
20–30 mmHgYellow
10–20 mmHgGreen
5–10 mmHgBlue
<5 mmHgPurple
These oxygen ranges are visualization bins and are not experimentally validated MCF-7 hypoxia thresholds.

In the current model, oxygen is used mainly for spatial visualization. Oxygen-dependent radiosensitivity / OER is planned as a future extension.

3D Spheroid and Cutaway Visualization

Each simulated cell was assigned independent x, y, and z coordinates:

xi = (xi, yi, zi)

The simulation was extended from 2D into true 3D to better represent the spatial organization of a tumor spheroid.

Because outer cells hide the spheroid interior, a half-cut visualization was created by displaying only cells on one side of the plane:

xi ≤ 0

Hidden cells are removed only from the rendering. They remain present in the underlying simulation.

Discussion

The model showed that 4 Gy suppressed cell growth more strongly than 2 Gy, while estrogen increased modeled proliferation. Surviving cells were able to regrow after irradiation.

The 3D oxygen visualization also showed spatial differences inside the spheroid. However, oxygen is currently used mainly for visualization and is not yet directly linked to radiation sensitivity.

Overall, this is a proof-of-concept computational model. Future work will include repeated simulations, parameter testing, and comparison with experimental MCF-7 spheroid data.

Future Work

  • Repeat simulations using multiple random seeds
  • Compare simulation outputs with laboratory-grown MCF-7 spheroids
  • Perform parameter sensitivity analysis
  • Implement oxygen-dependent radiosensitivity / OER
  • Investigate endocrine therapy and radiotherapy sequencing
